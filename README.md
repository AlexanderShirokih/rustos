# RustOS Mobile - Экспериментальное ядро мобильной ОС на Rust

Проект по созданию минималистичного ядра операционной системы для мобильных устройств с нуля на языке Rust.


## Ключевая концепция

Ядро проектируется как capability-based realtime микроядро, написанное на Rust. AArch64 является первой целевой платформой, но основная логика ядра не должна быть завязана на конкретную архитектуру процессора. Архитектурно-зависимый код изолируется в тонком `arch`-слое: загрузка, MMU, исключения, прерывания, таймеры и переключение контекста. Всё остальное ядро должно оставаться переносимым, проверяемым и независимым от деталей платформы.

Микроядро предоставляет только минимальный набор базовых механизмов: адресные пространства, потоки, планирование, IPC, таймеры, управление объектами ядра и правами доступа. Драйверы, файловые системы, сетевые стеки и системные сервисы должны работать в userspace. Такой подход уменьшает доверенную кодовую базу, упрощает отладку и делает систему устойчивее к ошибкам отдельных компонентов.

Доступ к ресурсам строится через capabilities — неподделываемые права на конкретные объекты ядра. В системе нет неявной глобальной власти: поток или процесс может использовать только те ресурсы, capabilities на которые были ему явно выданы или переданы. Права можно делегировать, ограничивать и отзывать, что делает изоляцию и композицию userspace-сервисов частью базовой модели системы, а не дополнительным слоем поверх неё.

Realtime-свойства закладываются в дизайн с самого начала. Планирование, IPC, синхронизация и управление ресурсами должны иметь предсказуемое поведение, короткие критические секции и контролируемые задержки. В критических путях ядро должно избегать скрытых глобальных зависимостей, неограниченных операций и сложных механизмов, которые трудно анализировать по времени выполнения.

Цель архитектуры — совместить простоту микроядра, безопасность capability-модели, realtime-предсказуемость и практическую производительность. Ядро должно быть маленьким по смыслу, строгим по правам доступа, переносимым по архитектуре и достаточно быстрым, чтобы оставаться пригодным для реальных систем, а не только для эксперимента.


## Запуск и поддерживаемые устройства 

**Целевое устройство**: Проект тестировался на Xiaomi Redmi Note 7 (lavender, Qualcomm SDM660), Raspberry Pi 5, QEMU. Вы можете попробовать собрать для другой модели телефона, однако вам придется доработать код самостоятельно
**Архитектура**: ARMv8-A (aarch64)

## Спецификации устройств

Конфигурации устройств хранятся в `devices/spec/*.yaml`:

```yaml
device:
  name: Device Name
  arch: aarch64

boot:
  format: binary | android_boot_v1 | android_boot_v2
  offset: 0x40200000
  dtb: /devices/dtb/device.dtb  # для android_boot_*

run:
  - "qemu-system-aarch64 -machine virt -cpu cortex-a53 -m 512M -nographic -kernel target/build/kernel.bin"

debug:
  - "qemu-system-aarch64 -machine virt ... -S -gdb tcp::1234"
```

- `format`:
  - `binary` — простой бинарник (QEMU, RPi)
  - `android_boot_v1` — boot.img с appended DTB, header version 1
  - `android_boot_v2` — boot.img с отдельным DTB, header version 2
- `offset` — адрес загрузки ядра (KERNEL_OFFSET)
- `dtb` — путь к Device Tree Blob (для Android)
- `run` — команды для запуска (`--run`)
- `debug` — команды для отладки (`--debug`)
