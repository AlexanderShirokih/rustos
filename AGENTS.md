# AGENTS.md

Индекс документации проекта RustOS Mobile. Детальная документация — в
[`docs/`](docs).

- Основные проверки (включает линт, тесты) — `cargo xtask check`
- Сборка загрузочного образа и запуск под QEMU —
  `cargo xtask build devices/spec/qemu-aarch64.yaml --run`
- Настройка окружения, toolchain, дополнительные проверки можно посмотреть в
  [`commands.md`](docs/commands.md)

## Навигация по коду

`rust-analyzer` входит в toolchain. Поиск определений, реализаций и
использований Rust-символов выполняется через LSP. Результаты доступны после
индексации workspace. Текстовый поиск применяется к строковым литералам,
комментариям, манифестам, YAML и линкер-скриптам.

## Дисциплина изменений

Изменения следуют [стилю кода](docs/code-style.md). Правка публичного контракта
обновляет его потребителей и документацию в том же изменении. Полнота миграции
проверяется через `findReferences`.

Документы `docs/` описывают архитектуру, возможности и общие контракты системы.
Устройство библиотеки и её API описывают её код и doc-комментарии. Планы работы
хранятся отдельно от описания текущей системы.

Наименование системы задаёт [workspace.md](docs/workspace.md#наименование).
