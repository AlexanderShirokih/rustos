## Навигация по коду

`rust-analyzer` входит в toolchain, и агент обращается к нему через свой
LSP-инструмент: в Claude Code это `LSP`, схема которого подгружается по
требованию через `ToolSearch`. Для поиска по символам такой поиск точнее
текстового: различает определение и упоминание, проходит сквозь
`pub use`-реэкспорты и не выдаёт совпадений в комментариях и строковых
литералах.

| Операция                        | Задача                                     |
|---------------------------------|--------------------------------------------|
| `workspaceSymbol`               | найти символ по имени во всех крейтах      |
| `goToDefinition`                | определение символа под курсором           |
| `findReferences`                | все использования символа                  |
| `goToImplementation`            | реализации типажа                          |
| `incomingCalls`/`outgoingCalls` | граф вызовов функции                       |
| `documentSymbol`                | оглавление файла без его чтения            |
| `hover`                         | сигнатура и тип символа                    |

Первые вызовы после старта сервера возвращают пустой результат, пока идёт
индексация: на заведомо используемом символе пустой ответ означает
«не проиндексировано», а не «ссылок нет», и вызов повторяется.

Текстовый поиск остаётся уместен там, где символов нет: строковые литералы,
комментарии, `TEST`-маркеры, `Cargo.toml`, YAML и линкер-скрипты.

## Дисциплина изменений

Правила ниже обязательны для каждого изменения; работа не считается законченной,
пока они не выполнены.

- [`docs/code-style.md`](docs/code-style.md) — норма, а не рекомендация.
  Перед сдачей работы дифф сверяется с ним целиком; особое внимание — разделам
  о комментариях и обработке ошибок: именно они чаще всего нарушаются.
- Правка публичного контракта (syscall ABI, форматы образов, IPC-контракты)
  не закончена, пока документация в `docs/` не обновлена тем же изменением.
- Полнота такой правки проверяется через `findReferences` (см. «Навигация по
  коду»), а не текстовым поиском.
- Находки вне объёма задачи выносятся в отчёт, а не исправляются молча.
- Пользовательский вывод (`println!`, `bail!`, `Display`, help-тексты) — только
  английский. Кириллица допустима исключительно в комментариях и документации.
- Сообщение коммита — одна строка на русском, без тела.
