# Синхронизация потоков процесса

Потоки одного процесса синхронизируются через futex, `Mutex` и `Condvar`.
Программы на стандартной библиотеке используют `std::sync`; её платформенная
реализация опирается на тот же futex. Межпроцессный обмен описан в
[ipc.md](ipc.md) и [port.md](port.md).

## Futex

Futex — атомарное слово в памяти процесса. Поток ждёт по его адресу, пока
значение равно ожидаемому. Смена значения, пробуждение или тайм-аут завершают
ожидание. Вызывающий проверяет условие в цикле, поскольку ложное пробуждение
допустимо.

Будящий сначала меняет слово, затем вызывает пробуждение. Поток, который ещё
не начал ждать, увидит новое значение. Пробуждение относится к уже ожидающим
потокам.

Реализация находится в [lib/runtime/src/futex.rs](../lib/runtime/src/futex.rs).
Число одновременно припаркованных потоков ограничено; при исчерпании слотов
ожидание продолжает проверять значение с уступкой процессора.
Снятие припаркованного потока оставляет его слот занятым до конца процесса.

## Mutex

`Mutex<T>` предоставляет взаимоисключающий доступ к значению. Захват
возвращает guard, освобождение которого снимает блокировку. Захват и
освобождение без конкуренции проходят в userspace; при конкуренции потоки
ждут на futex.

`RawMutex` — то же взаимоисключение без защищаемого значения. Захват и
освобождение — отдельные вызовы одного потока. Захват ждёт и со сроком по
монотонным часам процесса.

## Condvar

`Condvar` позволяет ждать изменения условия под мьютексом. Ожидание
отпускает мьютекс и захватывает его перед возвратом. Условие проверяется
в цикле после каждого пробуждения.

`RawCondvar` ждёт под `RawMutex`, в том числе со сроком по монотонным часам
процесса.

Условие меняется под мьютексом. Уведомлять можно и после освобождения
мьютекса. Уведомление не сохраняется для потока, начавшего ждать после него.

## Время жизни

Примитив синхронизации уничтожается после завершения всех потоков, которые
могут им пользоваться. Освобождение памяти примитива не снимает ожидание
по её адресу. `RawCondvar::destroy` дожидается уведомлённых потоков, после
него память `RawCondvar` можно освободить.

## Снятие потока

`ThreadTerminate` завершает другой поток текущего процесса
([syscalls.md](syscalls.md#thread)). Захваченные им мьютексы остаются занятыми,
включая возможную блокировку кучи.

Поток можно снимать после того, как он сам подтвердил безопасную точку:
общие ресурсы освобождены, обращения к куче закончены. Начало исполнения
функции, переданной в `spawn_owned`, само по себе такой точкой не является.
