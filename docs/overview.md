# Обзор проекта

RustOS Mobile — capability-based микроядро для aarch64 на Rust.

Ядро предоставляет минимальный набор примитивов: адресные пространства, потоки,
планирование, IPC, таймеры и capability-хендлы. Драйверы, файловые системы и
сетевые стеки живут в userspace и общаются с ядром и между собой через каналы.
Доступ к любому ресурсу идёт через хендл — токен на kernel-объект с набором
прав; неявной глобальной власти нет.

Платформенная конкретика — boot, MMU, прерывания, context switch — спрятана за
trait-интерфейсами, поэтому механизмы ядра (планировщик, память, IPC,
capability) не зависят от конкретного железа.

## Структура workspace

Крейты сгруппированы по доменам — верхним каталогам репозитория:

| Каталог   | Домен                                                     |
|-----------|-----------------------------------------------------------|
| `lib/`    | no_std-библиотеки, общие модели, IPC и бинарные контракты |
| `kernel/` | ядро: платформенный слой, механизмы, драйверы, сборка     |
| `user/`   | userspace-программы                                       |
| `tools/`  | host-инструменты для сборки образов                       |
| `xtask/`  | автоматизация сборки, запуска и тестов на host            |

Зависимости направлены вниз: `kernel/`, `user/` и `tools/` опираются на `lib/`,
но не наоборот. Полные правила и их проверка — в
[принципах архитектуры](architecture.md).

## Целевые платформы

Ядро не привязано к одному устройству: оно собирается под выбранную цель,
заданную device-спекой и платформенным слоем. Сейчас поддерживаются:

- QEMU `virt` — основная среда разработки и integration-тестов;
- Raspberry Pi 5;
- Xiaomi Redmi Note 7 (Qualcomm SDM660).
