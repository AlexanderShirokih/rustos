# Стиль кода

## Общие правила

- `#![no_std]` во всех крейтах ядра; `#![cfg_attr(not(test), no_std)]` если крейт тестируется с `std`.
- `extern crate alloc` для heap-аллокаций; `#[cfg(test)] extern crate std` для тестов.
- Rust Edition 2024: let chains, `#[unsafe(...)]` синтаксис.
- Все комментарии и документация пишутся на русском языке.
- Архитектурно-независимый код по умолчанию без `unsafe`; исключения
  должны быть локальными и сопровождаться `// SAFETY:`.

## Структура файла

Порядок элементов:

1. `//!` doc-комментарий модуля
2. `#![no_std]` и crate-level атрибуты
3. `extern crate`
4. `use` импорты (группировка: `core`/`alloc` -> внешние крейты -> `crate::`)
5. Константы и type alias'ы
6. Определения struct, enum, trait
7. `impl` блоки
8. Свободные функции
9. Макросы
10. `#[cfg(test)] mod tests`

## Комментарии

- Пишутся на русском языке.
- `//!` — описание модуля/крейта в начале файла.
- `///` — публичные элементы (структуры, функции, поля, варианты enum).
- `//` — только для неочевидных инвариантов, ограничений или обходов.
- Комментарий `// SAFETY:` обязателен перед каждым `unsafe` блоком с объяснением безопасности.
