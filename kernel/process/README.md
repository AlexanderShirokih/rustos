# process

Подготовка user-процессов на стороне ядра: сборка [`UserImage`] из образа,
валидация инвариантов, загрузка сегментов, построение per-process
VM-аллокатора и точка входа user-thread.

## Политика размещения стека

Вершина user-стека для всех образов фиксирована и равна верху user-диапазона
(потолок user-VA арха). Значение арх-специфично и им владеет арх-слой -
`ArchContext::USER_VA_END`; крейт `process` арх-нейтрален и принимает потолок
параметром (`user_image_parts_from_entry(entry, user_va_end)`), а не хардкодит.

Стек занимает `[user_va_end - stack_size, user_va_end)`; `stack_size` берётся
из заголовка образа.

Следствие контракта: образ обязан целиком лежать ниже `user_va_end -
stack_size`. Непрерывный образ не может занять весь user-диапазон - под стек
зарезервирован его верх. Пересечение стека со старшими сегментами отвергает
`UserImage::validate`.
